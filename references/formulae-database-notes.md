## KEY EQUATIONS FOR RELAY 1 (FIRE) IMPLEMENTATION

### EQ-001: HICE (The Player Score)
**H = I × E × C**
- I = Intelligence Quotient (scaled 0.1–10.0)
- E = Emotional Quotient (scaled 0.1–10.0)
- C = Creative Quotient (scaled 0.1–10.0)
- H range: 0.001 to 1000

### EQ-002: Signal Formula
**S = (A × P) / β**
- A = Amplitude (reach/scope)
- P = Persistence (duration of impact)
- β = Resistance (the 4Cs: Conflict, Climate, Contagion, Cost)

### EQ-013: ICE Cube Scaling (for IQ and EQ)
**Scaled = (Raw − 70) / 90 × 9.9 + 0.1**
- Input: Raw score 70–160
- Output: Scaled value 0.1–10.0

### CQ Scaling (for Creative Quotient)
- CQ uses **relay completion lookup** (not the linear formula)
- 0 relays = 0.1, 12 relays = 10.0
- Scale: n/12 mapped to 0.1–10.0
